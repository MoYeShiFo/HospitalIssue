# 增量补丁 · v1.18.81 —— 机构管理支持项目经理维护（下拉选择公司用户）

## 本版新增了什么

机构管理（平台管理员）每个机构新增**项目经理**维度：

- **列表**：机构表格新增「项目经理」列，未设置灰显；
- **维护**：操作列新增「项目经理」按钮 → 弹窗下拉选择（数据源 = 全局**启用的公司用户**，含显示名+账号；公司用户可跨机构归属，不限本机构成员），选「未设置」即清空；
- **校验**：服务端强校验——必须是存在且启用的**公司用户**（院方账号/任意数字一律 400，不存在 404）；改名/启停操作不影响已设项目经理；
- **审计**：项目经理变更记入操作日志（旧值→新值，含账号）；
- 新接口 `GET /api/orgs/company-users`（仅平台管理员）供下拉数据源。

## 升级说明（含数据库平滑加列）

- SQL Server 生产库：`dbo.app_org` 新增 `project_manager BIGINT NULL`——服务启动时**自动执行** `IF NOT EXISTS` 加列，无需手工 SQL；`schema.sql` 已同步。
- 未设置时存 NULL，历史数据零影响。

## 应用方式（增量覆盖，不影响数据）

1. 停止服务；
2. 将本补丁包内 `backend/`、`frontend/` 整目录覆盖到安装根目录对应位置；
3. 重新启动服务（mssql 驱动启动时自动补列）。

**本补丁不包含、也不会覆盖**：`.env` / `.env.example`、`backend/data/`、`backend/uploads/`、
`backend/node_modules/`、`runtime/`——服务器配置与数据零风险。
