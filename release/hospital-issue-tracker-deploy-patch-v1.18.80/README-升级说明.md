# 增量补丁 · v1.18.80 —— 问题登记支持 Excel 批量导入 + 角色可见范围

## 本版新增了什么

「问题登记」菜单两项增强：

### 1. Excel 批量导入
- 工具栏新增「批量导入」按钮：**下载导入模板 → 按模板填写 → 选文件解析预览 → 确认导入**；
- 模板表头与「导出」列完全一致（中文表头），单次上限 **500 行**；
- 逐行校验、**行级错误不中断整体**：导入完成后显示成功/失败汇总与每一失败行的行号+原因；
- 登记人未填时缺省为**导入人**显示名；登记账号（createdBy）恒为导入人本人（服务端注入，防伪造）；
- 导入记录与手工登记一致进入「待审核」流程。

### 2. 角色可见范围（列表 / 详情 / 导出同口径）
| 角色 | 可见范围 |
| --- | --- |
| 平台管理员 | 全部 |
| 院方管理员（机构管理员） | 全部 |
| 登记员 | 自己登记的（登记账号匹配；兼容代登记/导入时登记人姓名匹配） |
| 公司用户 | 处理人或登记人是自己（姓名），或登记账号是自己 |

- 详情按 id 读取同样受限：越权读取一律 **404**（与跨机构红线同一口径）；
- 导出（Excel/CSV）同样遵循可见范围：登记员只导出自己的，公司用户只导与自己相关的；
- 无法识别身份的异常账号 **fail-closed**（一条不可见），不会退化为看全部。

## 升级说明

- SQL Server 生产库：**本版无表结构变更**，无需加列；
- dev 驱动（JSON）与 mssql 驱动行为逐条等价（mssql viewer 过滤 SQL 已加静态断言防回退）。

## 应用方式（增量覆盖，不影响数据）

1. 停止服务；
2. 将本补丁包内 `backend/`、`frontend/` 整目录覆盖到安装根目录对应位置；
3. 重新启动服务。

**本补丁不包含、也不会覆盖**：`.env` / `.env.example`、`backend/data/`、`backend/uploads/`、
`backend/node_modules/`、`runtime/`——服务器配置与数据零风险。
